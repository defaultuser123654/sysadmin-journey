## День 2
- systemctl restart — стоп+старт одной командой, применяет новый конфиг
- systemctl enable — настраивает автозапуск сервиса при загрузке системы (не запускает сейчас)

-sudo journalctl -f  покажет живой лог в реальном времени
-sudo journalctl -u ssh покажет весь лог именно по ssh
-ss tulnup проверка открытых портов, ключевая для security-аудит сервера
-ip addr show покажет все сетевые интерфейсы 
-ping -c 4 google.com проверит есть ли у сервера доступ в интернет  (флаг -с сделает 4 попытки и остановится , иначе будет пинговать бесконечно)
-curl -I https://google.com отправит запрос на сайт и покажет только заголовки ответа  (HTTP status, server, etc) часто используется для проверки жив ли сайт/апи
